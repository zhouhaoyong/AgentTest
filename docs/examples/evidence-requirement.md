# evidence 目录契约示例

## 目录职责

保存当前 Version 的正式测试或回归测试中，用于支持具体问题或结论的证据。

## 允许内容

- 截图、Trace、HAR、录像和不含敏感信息的文字证据。
- 本文件：目录契约。

## 文件职责

每份证据都要能关联到测试用例和具体问题，并保留足以判断原始页面状态的内容。

## 更新规则

只在实际发生异常或需要支持结论时保存；测试报告使用相对路径引用。数据前置缺口、页面读取阻塞和功能缺陷需要分别说明。

## 禁止事项

- 不保存账号、密码、Token、Cookie、Storage State、验证码或其他登录态。
- 不用裁剪、遮挡或修改普通业务数据来代替敏感信息处理；敏感信息不得进入测试产物。
