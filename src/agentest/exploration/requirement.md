# exploration 目录契约

## 目录职责

为自然语言驱动的探索/发现阶段提供纯逻辑兜底：探索预算硬熔断、单会话批量验证候选定位、候选定位稳定性打分。这些能力被提示词工作流调用，用来把"反复死磕、逐次试错、把数据当结构"的黑洞下沉为可被程序强制的判据，不改变探索仍由提示词驱动的范式。

## 允许内容

- `budget.py`：ExplorationBudget 探索预算状态机，到点直接止损（入口重试 / 无进展 / 步数 / 时间）。
- `discovery.py`：单会话内批量解析候选定位（LocatorCandidate → Discovery），内置重试，结合打分排序；page 只需 duck-typed。
- `scoring.py`：score_locator 给单条候选定位打稳定性分，标记疑似数据派生的降权项。
- `__init__.py`：导出上述能力。
- 本文件：目录契约。

## 文件职责

三个模块都是纯逻辑、无文件副作用，把"选哪个定位入库 / 何时停手"的判断留给调用方，只给出机器可读依据。discovery 依赖 duck-typed page，可无浏览器单测。

## 更新规则

判据（定位优先级、弱定位启发式）必须与 asset_audit 的静态弱定位校验对齐，避免入库期与发现期两套标准打架。

## 禁止事项

- 不新增命令行入口或独立可执行程序；AgentTest 由自然语言/提示词驱动。
- 不做文件副作用、不在模块内启动真实浏览器。
- 不引入没有当前用途的抽象或配置。

## 阅读策略

修改探索预算或定位判据前先读本契约，再只读相关模块。
