# tests 目录契约

## 目录职责

保存 AgentTest 脚手架、Schema、浏览器配置、CLI 和架构边界的自动化测试。

## 允许内容

- `test_*.py`：按主题拆分的自动化测试。
- 本文件：目录契约。

## 文件职责

测试应验证用户可观察行为和安全约束，不应只验证无关的内部实现细节。

## 更新规则

新增行为时先写测试，再修改生产代码。修改后运行相关测试和完整测试套件。

## 禁止事项

- 不放生产代码。
- 配置测试不要求本机已经安装真实 Chromium。
- 不执行 Git 操作，也不修改用户真实 Project。

## 阅读策略

先读本契约，再运行最小相关测试，最后运行完整测试套件。
