# bugs 目录契约

## 目录职责

保存本 Version 最近一次正式测试发现的问题。

## 允许内容

- `bugs.md`：带稳定 ID 的轻量 Bug 记录。
- 本文件：目录契约。

## 文件职责

每个 Bug 关联 Test Point、测试维度、复现步骤、实际结果和预期结果。

## 更新规则

根据最近一次正式测试结果新增或更新 Bug。

## 禁止事项

- 不把本目录扩展为独立 Bug 管理系统。
- 不记录与当前范围无关的问题，除非明确说明风险和关联关系。

## 阅读策略

更新 Bug 前先读最近一次 Result 和已批准的 Test Points。
