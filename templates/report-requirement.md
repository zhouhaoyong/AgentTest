# report 目录契约

## 目录职责

保存本 Version 最近一次正式测试的简洁汇总报告。

## 允许内容

- `report.md`：范围、整体结果、测试点、Bug、未测试内容、风险和结论。
- 本文件：目录契约。

## 文件职责

报告汇总 Result 和 Bugs，不替代详细执行结果或 Bug 记录。

## 更新规则

报告必须明确未覆盖或被阻塞的功能、业务流和权限维度。

## 禁止事项

- 不用报告替代详细 Result 或 Bug。
- 重要测试维度未执行时，不得写成需求已完成。

## 阅读策略

写报告前先读 `run/result.md` 和 `bugs/bugs.md`。
