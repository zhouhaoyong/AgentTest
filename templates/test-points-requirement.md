# test-points 目录契约

## 目录职责

保存本 Version 可供人工审核的测试点资产。

## 允许内容

- `test-points.md`：稳定 Test Point ID、优先级、关联需求、测试维度、步骤和预期结果。
- 本文件：目录契约。

## 文件职责

测试点来自需求、分析、系统探索、Memory 和 Element Map，并定义正式测试的明确范围。

## 更新规则

生成测试点后必须停止，等待用户明确批准。用户可以直接修改 Markdown。

## 禁止事项

- 未批准的测试点不得正式执行。
- 不得静默扩大已批准范围。
- 相关时不得省略功能、业务流或权限评估。

## 阅读策略

执行已批准测试前，先阅读本契约和完整的 `test-points.md`。
