# Element Map 目录契约

## 目录职责

保存当前 System 可复用的界面和交互元素知识。

## 允许内容

- `index.md`：简短模块索引。
- `modules/`：模块级 YAML 或 Markdown 文件。
- 本文件：目录契约。

## 文件职责

模块文件只记录测试真正使用、后续可能复用或有助于理解 System 的元素。

## 更新规则

探索或正式测试发现有长期价值的新知识时才更新。模块文件名使用小写连字符格式，例如 `contact-list.yaml`。

## 禁止事项

- 不记录全部 DOM 节点。
- 不在每个 Version 下复制 Element Map。
- 不默认加载所有模块。

## 阅读策略

先读 `index.md`，确定相关模块后，再读取对应模块文件。
