# test-cases 目录契约

## 目录职责

保存本 Version 或联动范围可供人工审核的测试用例资产。

## 允许内容

- `test-cases.md`：按测试范围、功能测试、业务流程测试及按需增加的角色与权限测试组织的测试用例，包含稳定 Test Case ID、优先级、关联需求、测试步骤和预期结果，并记录未覆盖 / 阻塞项、开放问题和风险。
- 本文件：目录契约。

## 文件职责

测试用例来自需求、按需系统探索、Memory 和 Element Map，并定义当前范围正式测试的唯一范围。

## 更新规则

生成测试用例后必须停止，等待用户明确批准。用户可以直接修改 Markdown；开始测试前 Agent 必须重新读取当前文件的完整内容。

## 禁止事项

- 未获得用户明确授权时不得正式执行。
- 不得静默扩大已批准范围。
- 相关时不得省略功能、业务流程或角色 / 权限评估。

## 阅读策略

执行已批准测试前，先阅读本契约和完整的 `test-cases.md`。
