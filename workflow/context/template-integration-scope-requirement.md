# 联动范围目录契约

## 目录职责

本目录保存多个 System 一起完成一个需求时的测试资产。

## 允许内容

- `scope.yaml`：参与的 System、Version、测试地址和说明。
- `requirements/`：原始来源和整理后的联动需求。
- `test-points/`：当前联动范围的测试点。
- `test-scripts/`：可重复执行的联动测试脚本。
- `evidence/`：本次联动测试的 Bug 证据（截图、Trace、HAR、录像等），按需创建，不含凭据。
- `report/`：最近一次正式测试或回归测试的报告。
- 本文件：目录契约。

## 更新规则

先确认参与系统和操作顺序，再整理需求、按需探索并生成测试点。各子目录使用同名公共模板和目录契约。测试点完成后必须等待用户明确批准；只有用户明确说“开始正式测试”后，才批量准备脚本、分组调试并执行测试。

## 禁止事项

- 不把 System 的长期 Memory 或 Element Map 复制到这里。
- 不保存账号、密码、Token、Cookie 或其他凭据。
- 不用其他联动范围的资产静默覆盖本目录。

## 阅读策略

先读本契约和 `scope.yaml`，再按其中顺序读取相关 System、Version 与本目录资产。
