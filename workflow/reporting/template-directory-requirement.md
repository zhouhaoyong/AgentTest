# report 目录契约

## 目录职责

保存本 Version 或联动范围最近一次正式测试或回归测试的完整报告。

## 允许内容

- `report.md`：本次测试范围、脚本、测试用例结果、结果汇总、Bug、回归记录、未测试 / 阻塞内容、风险、建议和结论。
- 本文件：目录契约。

## 文件职责

报告统一承载测试结果、Bug 记录和回归信息，不再拆分 `run/`、`bugs/` 和独立结果文件。

## 更新规则

每次正式测试或回归测试后更新报告。报告必须明确本次执行类型、未覆盖或被阻塞的功能、业务流程和角色 / 权限维度，并给出测试建议。本次结果统计只能基于本次执行的 Test Case；回归测试必须单独记录历史结果与本次结果，不能混合统计。

## 禁止事项

- 重要测试维度未执行时，不得写成需求已完成。

## 阅读策略

写报告前先读已批准的 Test Cases、相关测试脚本和 System 级索引。
