# 系统探索 Prompt

你正在理解当前需求涉及的页面、模块、流程和可复用元素；探索不等于正式测试。

## 进入条件

- 用户明确要求探索，或需求整理后的探索决策为“目标探索”或“必须探索”。
- 若结论是“复用已有知识”，不进入本阶段，直接设计测试点。

## 必读资料

1. 根目录 `AGENTS.md`、[`workflow/README.md`](../README.md) 和当前 Version 或联动范围的结构化需求。
2. 相关 System 的 `system.yaml`、`element-map/index.md`、`memory/index.md` 及与需求直接相关的模块文件。

## 决策与执行

每次探索开始前，先用一句话说明“做什么”，再用一句话说明“为什么”；探索只能补足页面事实，不能替代需求审查。

1. **复用已有知识**的条件是相关模块、流程和定位已覆盖且仍适用；此时记录依据并直接移交测试点。
2. **目标探索**只查看缺失或可能过期的相关页面、流程、元素和依赖。多个 System 时，只探索各自缺失的部分和交接结果。
3. **必须探索**补足缺失的关键页面流程、权限、状态、依赖或需求冲突证据。
4. 页面探索不能替代需求审查。始终区分业务期望、当前页面实现和无法判断的差异；页面与需求不一致时记录为“页面事实差异”，必要时按编号向用户追问，不擅自改写需求；不创建 PASS、FAIL 或 Bug 结论，不修改业务数据。
5. 浏览器优先使用内置隔离浏览器；没有内置浏览器时，使用能创建新无痕 / 隔离会话的 Playwright 能力。不能创建新隔离会话的连接方式不可用。禁止复用用户当前已打开的浏览器窗口、Tab、Profile 或地址；必须使用新建的隔离 Chrome 会话。若没有可用能力，先询问用户是否需要 Agent 协助安装或启用，未确认前不打开浏览器。
6. **只要打开浏览器就开始记录 Element Map**：探索中实际操作过并验证的页面、元素和定位当场沉淀，探索结束即产出第一版 Element Map 供本次测试直接复用，不等到第一次版本测试之后再记。仍只保留有长期复用价值的信息，并为布局相关的元素记录**验证时的视口/窗口尺寸**。定位优先级为测试属性、语义定位、稳定属性 CSS、稳定文本、XPath。
7. **分离“到达”与“读取”，按成本择优进入目标**：到达某个模块不以读懂整页为前提。优先尝试深链直达（直接导航到目标 URL），并现场校验是否真的落在目标页（比对 URL 或目标页专属锚点）；若被重定向回登录 / 首页，退到用稳定导航文案点击，再退到站内搜索 / 快捷入口。把当次验证成功的到达方式记进 Element Map 的模块入口，不预设固定路由，也不针对单一项目写死路径。

## 探索预算与范围锚定

- **先锚定范围**：探索开始前，把本次需求涉及的功能路径列成一张清单（例如“通讯录-新的朋友-已处理列表”“我发布的订单”）；进入任何入口或页面前先自检它是否属于清单，不属于就不进、也不记入 Element Map。验证导航或环境时偶然路过的无关页面不纳入沉淀。
- **重试预算**：同一入口或同一次读取连续失败约 3 次即停，不反复硬试；改走到达降级链或停下反问。
- **无进展预算**：连续若干步没有新增“已验证事实”（没进新页面、没记到新元素）就停下，向用户说明当前进展并反问如何继续。
- **总量兜底**：单轮探索设一个粗粒度的时间或步数上限（如约 1 小时）作为兜底；真正可靠的硬超时应由运行 Agent 的调度层设置，本 Prompt 只作软约束。
- **触发即止损**：任一预算触发、或读取 / 导航连续超时时，主动提出“疑似反调试 / devtools 检测或环境阻塞”的判断并停下反问，先把已确认的稳定事实沉淀，不擅自绕过、不继续空耗 token。

## 允许写入的位置

- 仅写入对应 System 的 `element-map/`、`memory/` 及其索引；不复制到 Version 或联动范围。
- 不记录完整 DOM、临时日志、推理过程、凭据或一次性会话信息。
- Memory 模块中的每条事实必须注明“验证 Version”“长期用途”和“稳定事实”；一次性测试结果、Bug 结论、临时网络错误或截图失败只写入报告。

## 交付物与移交方向

- 记录实际采用的探索策略、参考的模块和新确认的长期信息。
- 移交 `test-points/`；测试点范围必须简要写明“复用已有知识”“目标探索”或“必须探索”及依据。

## 强制停止条件

- 遇到登录立即暂停，由用户手动完成并明确确认后再继续。
- 无法确认浏览器隔离、需求目标或页面事实时立即停止并按编号提问。
- 用户只要求探索时，在本阶段结束；不得自行进入正式测试或扩大探索范围。
