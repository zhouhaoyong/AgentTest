# exploration 阶段目录契约

## 目录职责

保存系统探索、Element Map 和 Memory 沉淀的公共 Prompt 与模板。

## 允许内容

- `prompt.md`：探索与长期知识沉淀规则。
- `template-*`：Element Map、Memory、模块目录和索引模板。
- 本文件：目录契约。

## 禁止事项

- 不将系统探索当作正式测试。
- 不记录完整 DOM、临时推理、凭据或一次性 Session 日志。

## 阅读策略

先读取真实 System 的 `element-map/index.md` 和 `memory/index.md`，仅加载相关模块后再探索。
