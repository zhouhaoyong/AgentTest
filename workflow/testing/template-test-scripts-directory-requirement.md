# test-scripts 目录契约

## 目录职责

保存本 Version 可重复执行的测试脚本。

## 允许内容

- 按测试点组织的 Python Playwright 脚本。
- 本文件：目录契约。

## 文件职责

每个测试脚本应关联一个或多个稳定的 Test Point ID，并说明必要的前置条件、执行方式和结果判断。脚本至少应支持当前 Version 内的重复测试，并用于正式测试和 Bug 修复后的回归测试；已确认需求发生变化时，应及时调整脚本。

## 更新规则

测试点确认后可以创建或调整脚本。Bug 修复后优先复用相关脚本回归；脚本行为变化时同步更新测试点或报告说明。

## 禁止事项

- 不保存密码、Token、Cookie 或其他凭据。
- 不保存 Storage State；脚本、日志、截图、Trace、HAR 和视频中也不得出现敏感信息。
- 普通业务数据的 Bug 证据不要求脱敏，不得为了脱敏而影响问题判断。
- 遇到登录必须暂停，等待用户手动输入账号密码并明确确认完成。
- 不把临时探索代码当成正式测试脚本。
- 不自动扩大脚本覆盖范围。

## 阅读策略

先读已批准的 `test-points/test-points.md`，再按需读取相关脚本。
