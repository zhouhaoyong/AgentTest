# testing 阶段目录契约

## 目录职责

保存已批准测试用例的正式执行 Prompt、批量脚本准备、分组调试、等待熔断和正式测试规则。

## 允许内容

- `prompt.md`：正式测试执行规则。
- `rules.md`：定位、登录、范围和安全规则。
- `template-*`：真实测试脚本目录契约和脚本骨架。
- 本文件：目录契约。

## 禁止事项

- 未获批准不得正式测试；测试用例确认不等于启动，只有用户明确说“开始正式测试”后才能打开浏览器；不得自动填写凭据或扩大范围。
- 不在公共目录保存真实脚本、截图、Trace、HAR、视频或结果。

## 阅读策略

用户明确批准测试用例后读取 `prompt.md` 和 `rules.md`，再读取当前 Version 或联动范围的真实资产。
