# evidence 目录契约

## 目录职责

保存当前 Version 本次正式测试或回归测试的 Bug 证据。

## 允许内容

- 截图、Trace、HAR、录像和不含敏感信息的文字证据。
- 本文件：目录契约。

## 文件职责

证据必须关联 Test Case 和具体问题，保留足以判断页面原始状态的内容，不保存账号、密码、Token、Cookie、Storage State 或验证码。

## 更新规则

只在实际发生异常或需要支持结论时保存证据；报告使用相对路径引用。数据缺口、页面读取阻塞和功能缺陷应在报告中分开说明。

## 禁止事项

- 不保存任何凭据或登录态。
- 不用修改、裁剪或遮挡普通业务数据来替代敏感信息处理；敏感信息不得进入测试产物。
